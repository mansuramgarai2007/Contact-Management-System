📞 Contact Management System

📌 Project Overview

The Contact Management System is a console-based application developed using Python 3. It helps users manage their contacts efficiently by performing basic CRUD (Create, Read, Update, Delete) operations.

Users can add new contacts, view all saved contacts, search for contacts by name, update existing contact details, and delete contacts.

This project demonstrates the practical implementation of Python programming concepts such as Lists, Dictionaries, Functions, Loops, Conditional Statements, and CRUD operations.

🎯 Objectives

- To develop a simple and user-friendly contact management application.
- To perform CRUD operations on contact records.
- To validate phone numbers.
- To prevent duplicate phone numbers.
- To understand the practical use of Python data structures and functions.

✨ Features

- ➕ Add Contact: Add a new contact with name, phone number, and email.
- 📋 View Contacts: Display all saved contacts.
- 🔍 Search Contact: Search for contacts using their names.
- ✏️ Update Contact: Modify existing contact information.
- 🗑️ Delete Contact: Remove a contact from the contact list.
- ✅ Phone Validation: Ensures phone numbers contain exactly 10 digits.
- 🚫 Duplicate Prevention: Prevents adding an already registered phone number.
- 🚪 Exit Option: Provides a menu-driven exit option.

🛠️ Technologies Used

- Programming Language: Python 3
- Concepts: Lists, Dictionaries, Functions, Loops, Conditional Statements
- Operations: CRUD (Create, Read, Update, Delete)
- Platform: Python IDLE / VS Code / PyCharm
